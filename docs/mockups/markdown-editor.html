The same gestures on mobile

Headings happen as you type

# + space→A new heading

The prefix disappears into the formatting. ## and ### create smaller headings. Undo restores the typed prefix.

A dash becomes a list

- + space→•   A new idea

Return continues the list. Return on an empty item returns to normal text. 1. starts a numbered list.
